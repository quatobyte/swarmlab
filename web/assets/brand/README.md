# Оформление стартовых экранов

Источник: авторский макет пользователя в [Figma](https://www.figma.com/design/QYVnEOSRZCJSwYUGUPBPpk/swarmlab).

- `sky.png` — исходная фотография облаков из макета.
- `title.svg`, `subtitle.svg` — оригинальные надписи, шрифт сохранён в векторных контурах.
- `footer-*.svg` — авторская нижняя строка логотипов.
- `brand-*.svg` — логотип шапки страницы проектов.
- `meadow.svg` — обложка карточки проекта из согласованного варианта.

Все ресурсы хранятся локально: приложение не обращается к временным адресам Figma.
