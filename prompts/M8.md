**Предусловие.** Ветка от `master`, рабочая копия чистая, `pytest` и `ruff check` зелёные. Если нет — остановись и скажи.

**Задача.** Всё из «Входит» M8 с закрытием каждого критерия приёмки. Решения согласованы с Лео 09.11 (грилинг) и записаны в DECISIONS №84–88 — это источник истины по именам и поведению.

**Указания:**
- **План сначала.** Сверь решения с кодом, составь план и покажи его до кода. Жди «ок». Если решение расходится с кодом или инвариантами `CLAUDE.md` — остановись и спроси.
- **Где что живёт.**
  - Раннер: `loop()` каждого агента — в своём `greenlet`; хост переключает их строго по порядку `uid`, бюджет меряет вокруг переключений в код игрока. Ждущая команда переключает обратно в хост; хост продолжает поток, когда модуль подтвердил выполнение (механизм `wait`-seq из №61 на стороне модуля остаётся). Конец прохода `loop` — ожидание следующего тика. Смерть — `greenlet.throw(GreenletExit)`, чтобы выполнился `finally`.
  - Модуль: автовозврат по порогу, заправка, случайный бак, остановка `search`/`explore` у цветка, `collect(место)`, случайная точка `explore` (поток `core.rng`, не `random` игрока) — всё в модуле, векторно, работает и когда раннер опаздывает. Порог и уровень заправки приходят командой улья.
  - Хост: `heard` копится между проходами `loop` (последнее сообщение от пчелы по каждому слову).
- **Свойства пчелы только для чтения.** Запись в `self.pos`, `self.energy` и другие поля API — исключение с понятным русским текстом; свои поля (`self.target`) пишутся как обычно.
- **Детерминизм.** Порядок переключений фиксирован, случайность — только из `core.rng` и засеянного `random`. Один seed + одни скрипты → одинаковый хеш реплея.
- **Ядро не знает модулей.** `greenlet` и программа агента — в раннере/`core/program.py` без импорта `bees`.
- **Реплей.** Новая версия формата; старый файл — ошибка «реплей старой версии».
- **Блоки.** Набор блоков и подсказки — генераторами из `api.py`; русские подписи — только в `blocks_ru.js`; генератор Python в блоках пишет `loop` без `yield`; блоки программ — `Scout`, `Collector`, `Hive`. Примеры `.blocks.json` пересобери.
- **Документы.** `PLAYER_API.md`, `CHEATSHEET.md`, `BEES_SPEC.md`, `ARCHITECTURE.md`, `README.md`, `DEMO.md`, шаблон — только новый API, простыми словами для школьника.
