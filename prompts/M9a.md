**Указания:**
- **План сначала.** Сверь решения с кодом, составь план (файлы, таблицы базы, маршруты, что меняется в клиенте, какие тесты где) и покажи его до кода. Жди «ок». Расхождение с решениями или инвариантами `CLAUDE.md` — остановись и спроси.
- **Где что делается (DECISIONS №98).**
  - Ядро, сервер, клиент `web/js/core/`, тесты аккаунтов и хранения без матчей — в `master`. Ядро не называет модуль по имени.
  - Части, которым нужен модуль (матч владельца, его реплей и WS, очистка реплеев после матчей, проверка в браузере), — в ветке `bees` после `git merge master`: тесты в `tests/server/` ветки `bees`.
  - Закрепить `mujoco>=4.0,<5` (№97) — в `pyproject.toml` ветки `bees` (в `master` MuJoCo нет).
- **Два режима (№95).** Без `--public` сервер работает ровно как сейчас — все прежние тесты `bees` проходят без изменений. Всё новое включается только флагом `swarmlab serve --public`.
- **Настройки портала** — YAML, не константы: умолчания в пакете (`src/swarmlab/server/public.yaml`, папка `configs/` принадлежит модулю), путь к своему файлу — `--public-config`. В нём: квоты реплеев (10 последних, 50 штук / 500 МБ, 7 дней), лимиты регистраций и входов, длина пароля, настройки cookie.
- **Данные пользователей** — папка `--data` (по умолчанию `<root>/data`, добавь в `.gitignore`): база `swarmlab.db` и `users/<id>/{scripts,projects,replays}/`. Пути строятся только из id пользователя, не из почты.
- **Аккаунты (№91, №97).** SQLite через стандартный `sqlite3`; пароли — `argon2-cffi` (новая зависимость ядра в `pyproject.toml` `master`). Сессия — случайный токен в HTTP-only cookie, `SameSite=Lax`, `Secure` — когда запрос пришёл по HTTPS (за прокси — по заголовку `X-Forwarded-Proto` только от доверенного адреса прокси из настроек); локально по `http://127.0.0.1` вход тоже должен работать. CSRF — токен в заголовке `X-CSRF-Token` на всех изменяющих запросах; `web/js/core/api.js` подставляет его сам. Почта — логин, хранится в нижнем регистре; писем нет.
- **Маршруты (предложение, уточни в плане):** `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/me`, `POST /api/me/password`, `DELETE /api/me`, `GET /api/me/export` (zip всех проектов и скриптов). Без входа в публичном режиме доступны только страницы входа и регистрации, статика и эти маршруты; остальное `/api/*` и WS — 401.
- **Ограничения частоты.** Регистрации — не больше 3 в час с одного IP, вход — временная блокировка после N неверных паролей. IP клиента за прокси берётся из `X-Forwarded-For` только если запрос пришёл от доверенного прокси (иначе за Caddy все пользователи — один IP).
- **Свои данные (№92).** Скрипты редактора и проекты `.swarm` — в папке пользователя; общие примеры модуля (`examples/<модуль>/`) видны всем только для чтения. Матч помнит владельца; матч, его WS, стоп, реплей — только владельцу, чужое — 404 (не 403: не раскрываем, что такое есть). Реплеи: последние 10 незакреплённых хранятся сами, «Сохранить» закрепляет (флаг в базе), закрепление сверх квоты — понятная ошибка, очистка незакреплённых старше 7 дней — при окончании матча и при старте сервера.
- **Серии в публичном режиме** в M9a выключены (403 с понятным текстом): лимиты серий — M9b.
- **Клиент.** Экран входа и регистрации, «Мои проекты», «Мои реплеи» (закрепить, скачать `.swr`, удалить), профиль (смена пароля, удаление аккаунта с предложением скачать архив, выход). Публичный режим клиент узнаёт по `GET /api/me` (401 → экран входа). Тексты — по-русски, простыми словами.
- **Удаление аккаунта** — с текущим паролем: строки в базе и папка пользователя удаляются, его матчи останавливаются.
- **Тесты.** `master`: аккаунты, сессии, CSRF, частота, разделение скриптов и проектов, удаление, локальный режим без изменений — через `create_app` во временной папке, без модуля. `bees`: матчи, реплеи и WS владельца, очистка реплеев, проверка в браузере (`.claude/launch.json` дерева `bees`, режим `--public`).
