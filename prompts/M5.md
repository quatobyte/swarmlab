Веха M5 — редактор кода в браузере.

Прочитай `CLAUDE.md`, `docs/ROADMAP.md` (M5). Посмотри, что сделано в M4 (`web/`, `server/`).

Задача: всё из «Входит» M5 с закрытием каждого критерия приёмки.

Указания:
- План сначала: какой редактор (офлайн, vendored, без npm-сборки — например, Monaco min-сборка с AMD-загрузчиком или CodeMirror в готовой ES-сборке; выбери и объясни), раскладка экрана (редактор | 3D | панель матча), API сервера для сохранения скрипта и перезапуска. Жди «ок».
- Сервер сохраняет только в `examples/bees/` (или `user_scripts/`), имя файла проверяется — никакой записи по произвольному пути.
- Ошибки: синтаксис проверяется сервером через `ast.parse` до запуска матча; ошибки и `print` из раннера каждого улья показываются в панели логов с номером строки.
- Панель матча: соперники (выбор скриптов), профиль, seed, переключатели шершней / пауков / погоды, длительность, кнопки «Запустить» и «Стоп».
- Подсветка синтаксиса Python и подсказки по API пчёл (хотя бы статический список методов и полей сенсоров).

Проверка: тесты, `ruff check`. Ручной чек-лист для меня:
1. Открыть шаблон, поменять поведение сборщиков, запустить — поведение изменилось.
2. Сделать синтаксическую ошибку — видна ошибка с номером строки, сервер жив.
3. Написать `while True: pass` в `step()` — матч идёт, в логах предупреждение о бюджете.
4. Выключить шершней — их нет.
