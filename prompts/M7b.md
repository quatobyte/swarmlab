Веха M7b — блоки в редакторе.

Прочитай `CLAUDE.md`, `docs/ROADMAP.md` (M7b), `docs/DECISIONS.md` (решения 50–56 и 60), `docs/BEES_SPEC.md` §3.1–3.3, `docs/PLAYER_API.md`. Посмотри, как устроены подсказки API (`tools/gen_api_hints.py`, решение 46) и редактор M5 (`web/`, `src/swarmlab/server/`).

**Предусловие.** M7a принята (`✅` в ROADMAP, тесты зелёные). Блоки опираются на `yield`, без M7a их нельзя проверить.

**Задача.** Всё из «Входит» M7b с закрытием каждого критерия приёмки.

**Указания:**
- **План сначала.** Ключевой вопрос: где живёт генерация Python — в браузере (JS) или на сервере (Python)? Выбери, объясни и покажи план. Учти: проверка `ast` идёт на сервере (`POST /api/scripts/check`), а блоки должны работать офлайн без пересборки. Жди «ок».
- **Структура блоков — из `api.py`** (DECISIONS 52): `tools/gen_blocks_api.py` строит описание блоков по тому же `ast`-подходу, что `gen_api_hints.py`. Русские подписи и подсказки — только в `web/js/modules/bees/blocks_ru.js`, вручную. Стартовый набор помечен «для новичков», остальное — «Продвинутые».
- **Программы** (DECISIONS 53): блоки «Программа пчелы» с выпадающим списком типа и «Программа улья». Одна программа на тип. Дубликат не генерируется и подсвечивается. Выполнение раз в тик, без блоков-событий.
- **Хранение** (DECISIONS 54): `my_bees.blocks.json` рядом с `my_bees.py`. Файл `.py` генерируется; вручную он не правится, пока пользователь в блочном режиме.
- **Сопоставление ошибок.** Каждая строка сгенерированного кода несёт комментарий `# block:<id>`. Ошибка `ast` показывается на блоке с этим id.
- **Проверка по порядку** (DECISIONS 56): сначала подключённость (неподключённые блоки серые и не ошибка), потом `ast`.
- **Рекурсия** (DECISIONS 55): в блоках — предупреждение при сборке через проход по графу вызовов процедур; в Python ничего не запрещаем.
- **Переключение в Python** (DECISIONS 50): предупреждение и подтверждение. После перехода блоки больше не обновляют `.py`.
- **Blockly** подключается так же, как CodeMirror: vendored в `web/vendor/`, версия записана в решении, без сборщика и без CDN.
- **Производительность.** Проверь, что добавление Blockly не роняет FPS вьюера на iGPU ниже 30 при профиле «Средний».
