# SwarmLab — ядро

Модульный 3D-симулятор роевых систем. Эта ветка (`master`) — **ядро без модулей**: цикл симуляции, конфиги и профили, seed-RNG, реплеи `.swr`, раннер кода игрока, CLI, сервер FastAPI и общий веб-вьюер (`web/js/core/`). Модулей-сценариев здесь нет — у каждого своя ветка (DECISIONS №98):

| Ветка | Что в ней | Рабочее дерево |
|---|---|---|
| `master` | ядро и общие документы | `D:\Files\Projects\swarmlab` |
| `bees` | ядро + модуль пчёлок (Swarm Logic) — играть и разрабатывать пчёл здесь | `D:\Files\Projects\swarmlab-worktrees\bees` |
| `city` | ядро + модуль «Город» (пока только ядро) | `D:\Files\Projects\swarmlab-worktrees\city` |
| `quarry` | ядро + модуль «Карьер» (пока только ядро) | `D:\Files\Projects\swarmlab-worktrees\quarry` |

Ядро правится только в `master` и вливается в ветки модулей (`git merge master`). Модуль правится только в своей ветке. Как это устроено — `docs/ARCHITECTURE.md` §2, правила работы — `AGENTS.md`.

## Установка (Windows, PowerShell)

У каждого рабочего дерева своё окружение `.venv` — пакет ставится в режиме `-e` из папки этого дерева.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m pytest
ruff check .
```

Для JavaScript-проверок нужен Node.js в `PATH` (`node --version`). Без него `pytest` пропускает эти проверки; для полного прогона установи Node.js и проверь причины пропусков через `python -m pytest -rs`.

Без модуля `swarmlab run` и редактор не работают: модуль ставится в его ветке, вместе с конфигами (`configs/`), примерами (`examples/`) и вьюером (`web/js/modules/<модуль>/`).

## Сервер: локально и портал

`swarmlab serve` — вьюер и редактор на `http://127.0.0.1:8000/` для одного человека, без входа.

`swarmlab serve --public` — портал (DECISIONS №90–97, `docs/ARCHITECTURE.md` §7.1): вход по почте и паролю, у каждого свои скрипты, проекты и реплеи. Текущие настройки включают nsjail для Linux. Для проверки аккаунтов на Windows создай отдельный локальный конфиг без песочницы:

```powershell
New-Item -ItemType Directory -Force .\data | Out-Null
'sandbox: {runner_prefix: []}' | Set-Content -Encoding utf8 .\data\public-local.yaml
swarmlab serve --public --host 127.0.0.1 --port 8001 --data .\data --public-config .\data\public-local.yaml
```

Открыть `http://127.0.0.1:8001/` → «Регистрация». Эта команда предназначена для локальной пробы со своим кодом: без песочницы код игрока получает права процесса сервера. Аккаунты можно проверить в `master`; редактор и матчи — в ветке модуля после переноса в неё изменений ядра.

База, папки пользователей и локальный конфиг из примера — в `--data` (по умолчанию `.\data`, в git не попадает). Настройки портала (квоты, лимиты, cookie, доверенный прокси, песочница) — `src/swarmlab/server/public.yaml`; свой файл поверх умолчаний — `--public-config мой.yaml`.

M9b начата, но приёмка не завершена: Dockerfile и профили в `docker/` — рабочие заготовки, изоляция в Linux и производительность на четырёх матчах ещё требуют проверки. Текущий вариант не готов к публичной эксплуатации. Статус и оставшиеся проверки — `docs/ROADMAP.md`.
