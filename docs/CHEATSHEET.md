# Памятка: как управлять роем пчёл

Ты пишешь программу для целого улья. Каждая пчела 10 раз в секунду спрашивает свою программу:
«Что мне делать?» Твоя задача — ответить так, чтобы к концу матча в улье было **больше всех мёда**.

## Как начать

1. Нажми **«Редактор кода»** в меню. Откроется файл `my_bees.py` — это копия шаблона.
2. Найди класс `MyForager` (сборщик). Удали строку `super().step(s)` и напиши свою логику.
3. Нажми **«▶ Запустить»** (или `Ctrl+Enter`). Код сохранится, проверится, и матч начнётся справа.
4. Смотри, что делают пчёлы, и читай **«Логи»** внизу. Поправил код — снова «Запустить».

## Где что писать

```python
class MyForager(Forager):         # сборщик
    def step(self, s):            # s — то, что пчела видит сейчас
        ...                       # здесь команды: self.fly_to(...), self.collect(...)

def hive_step(hive):              # улей: кого выводить
    ...
```

Есть ещё `MyScout` (разведчик), `MyGuard` (охранник), `MyHouse` (домашняя пчела).

## Что видит пчела (`s.…`)

| Пишешь | Что получаешь |
|---|---|
| `s.me.pos` | где я: `.x`, `.y`, `.z` (в метрах) |
| `s.me.energy_percent` | сколько энергии, от 0 до 100. **На нуле пчела падает!** |
| `s.me.cargo` | сколько нектара несу |
| `s.me.is_full` | `True` — груз полный |
| `s.me.in_hive` | `True` — я в улье |
| `s.home.pos`, `s.home.dist` | где мой улей и далеко ли до него |
| `s.flowers` | цветы рядом (у цветка: `.pos`, `.dist`, `.nectar`) |
| `s.nearest_flower(min_nectar=0.3)` | ближайший цветок с нектаром или `None` |
| `s.enemies`, `s.nearest_enemy()` | шершни рядом |
| `s.messages` | сообщения от своих пчёл (`.values` — числа) |
| `s.time` | сколько секунд идёт матч |

Пчела видит только то, что **близко**: разведчик — на 25 м, охранник — на 12 м, сборщик — на 8 м.

## Команды пчеле (`self.…`)

| Команда | Что делает | Кто умеет |
|---|---|---|
| `self.fly_to(x, y)` | лететь в точку | все летающие |
| `self.fly_dir(dx, dy)` | лететь в ту сторону | все летающие |
| `self.hover()` | висеть на месте | все летающие |
| `self.go_home()` | домой, в улей (там заправка) | все летающие |
| `self.leave_hive()` | вылететь из улья | все летающие |
| `self.collect(flower)` | собирать нектар с цветка | сборщик |
| `self.unload()` | выгрузить нектар (только в улье) | сборщик |
| `self.intercept(enemy)` | догнать врага | охранник |
| `self.signal(1, x, y)` | сказать своим рядом до 8 чисел | все летающие |
| `self.mark(0)` | оставить запах (каналы 0–3) | все летающие |
| `self.process()` | делать мёд из нектара | домашняя |
| `self.nurse()` | растить личинок | домашняя |
| `self.rest()` | отдыхать | домашняя |

Важно:

- Вызвал за тик несколько команд движения — сработает **последняя**.
- Ничего не вызвал — пчела продолжает прошлую команду.
- Хочешь что-то запомнить — сохрани в `self`: `self.my_flower = flower`.

## Улей (`hive.…`)

| Пишешь | Что это |
|---|---|
| `hive.honey` | сколько мёда |
| `hive.nectar` | сколько нектара ждёт переработки |
| `hive.counts.forager` | сколько сборщиков (и так же `.scout`, `.guard`, `.house`) |
| `hive.queue` | личинки в очереди |
| `hive.breed("forager")` | вывести новую пчелу (стоит мёда: сборщик — 4) |
| `hive.memory` | словарь, чтобы улей что-то помнил |

## Как получается мёд

**цветок → сборщик `collect` → домой `go_home` → `unload` → домашние `process` → мёд**

1 нектар превращается в 0.5 мёда. Мёд тратится на заправку пчёл, еду домашних и новых пчёл.

## Готовые кусочки

**Простой сборщик:**

```python
class MyForager(Forager):
    def step(self, s):
        if s.me.in_hive:                  # я дома
            if s.me.cargo > 0:
                self.unload()             # выгрузить нектар
            else:
                self.leave_hive()         # и снова в путь
            return
        if s.me.is_full or s.me.energy_percent < 30:
            self.go_home()                # полный или устал — домой
            return
        flower = s.nearest_flower(min_nectar=0.3)
        if flower is not None:
            self.collect(flower)          # собирать
        else:
            self.fly_to(s.home.pos.x + 20, s.home.pos.y)   # искать дальше
```

**Разведчик рассказывает про цветы:**

```python
class MyScout(Scout):
    def step(self, s):
        flower = s.nearest_flower(min_nectar=1.0)
        if flower is not None:
            self.signal(flower.pos.x, flower.pos.y)   # «цветы вот тут!»
        super().step(s)                               # дальше летает как обычно
```

**Сборщик слушает разведчиков:**

```python
for msg in s.messages:
    if len(msg.values) >= 2:              # в сообщении есть x и y
        x, y = msg.values[0], msg.values[1]
        self.fly_to(x, y)
```

**Улей выводит сборщиков, когда мёда много:**

```python
def hive_step(hive):
    if hive.honey > 30 and not hive.queue:
        hive.breed("forager")
```

## Если что-то пошло не так

| Видишь | Что случилось | Что делать |
|---|---|---|
| Красный крестик у строки, «Синтаксическая ошибка» | опечатка: забыл `:`, скобку или кавычку | нажми на ошибку — редактор покажет строку |
| «Ошибка отступа» | строки внутри `if`, `for`, `def` должны сдвигаться на 4 пробела | выровняй отступы (`Tab` — 4 пробела) |
| В логах `File "my_bees.py", line 25` и `NameError` / `AttributeError` | ошибка в 25-й строке: опечатка в имени | нажми на ссылку в логе и проверь имя |
| В логах «не уложился … бюджет» | код думает слишком долго, например `while True` | убери бесконечный цикл |
| Пчёлы падают | закончилась энергия | раньше отправляй домой: `energy_percent < 30` |
| Мёд не растёт | сборщики не выгружают нектар или домашние не работают | проверь `unload()` и `process()` |
