# Памятка: как управлять роем пчёл

Ты пишешь программу для целого улья. Твоя задача — чтобы к концу матча в улье было
**больше всех мёда**.

Главное: у всех пчёл одного типа **одна и та же программа**, и каждая видит только то, что рядом.
Командира с картой нет — пчёлы договариваются сами: говорят слова (`say`) и оставляют запахи (`mark`).

## Как начать

1. Нажми **«Редактор кода»** в меню. Откроется файл `my_bees.py` — это копия шаблона.
2. Найди класс `MyCollector` (сборщик). Удали строку `super().loop()` и напиши свою логику.
3. Нажми **«▶ Запустить»** (или `Ctrl+Enter`). Код сохранится, проверится, и матч начнётся справа.
4. Смотри, что делают пчёлы, и читай **«Логи»** внизу. Поправил код — снова «Запустить».

## Где что писать

```python
class MyCollector(Collector):     # сборщик
    def loop(self):               # что делать — игра повторяет это снова и снова
        flower = self.explore()   # искать цветы
        if flower:
            self.collect(flower)  # собрать нектар
        self.go_home()            # домой

class MyHive(Hive):               # улей: кого выводить
    def loop(self):
        ...
```

Есть ещё `MyScout` (разведчик). Домашние пчёлы (`Worker`) работают сами: делают мёд и растят личинок.

**Команды движения ждут сами:** строка `self.fly_to(flower)` закончится, когда пчела долетит.
Поэтому программа читается как рассказ — сверху вниз.

## Что знает пчела (`self.…`, только читать)

| Пишешь | Что получаешь |
|---|---|
| `self.pos` | где я: `.x`, `.y` (в метрах) |
| `self.energy` | сколько энергии, от 0 до 100 %. **На нуле пчела падает!** |
| `self.nectar` | сколько нектара несу |
| `self.is_full` | `True` — груз полный |
| `self.at_home` | `True` — я дома, в улье |
| `self.home` | где мой улей |
| `self.flowers` | цветы рядом (у цветка: `.pos`, `.nectar`, `.distance`) |
| `self.nearest_flower(min_nectar=0.3)` | ближайший цветок с нектаром или `None` |
| `self.bees` | пчёлы рядом (`.friend` — своя ли) |
| `self.heard` | что я услышала (`.word` — слово, `.where` — место) |
| `self.smell("red")` | чую ли красный запах |
| `self.time` | сколько секунд идёт матч |

Пчела видит только то, что **близко**: разведчик — на 25 м, сборщик — на 8 м.
Свои данные храни под своими именами: `self.my_flower = flower`. А `self.pos = …` — нельзя.

## Команды пчеле (`self.…`)

| Команда | Что делает |
|---|---|
| `self.fly_to(цель)` | лететь к цветку, пчеле, месту из сообщения или `(x, y)`; `True` — долетела |
| `self.explore()` | искать цветы вокруг дома; вернёт цветок или `None` |
| `self.search(цель)` | лететь к цели, но остановиться у первого цветка с нектаром |
| `self.collect(цветок)` | (сборщик) собирать нектар; `True` — груз полный |
| `self.go_home()` | домой, в улей: нектар выгрузится сам |
| `self.refuel(80)` | дома заправиться до 80 % |
| `self.wait(2)` | подождать 2 секунды |
| `self.stop()` | остановиться и висеть |
| `self.say("flowers", flower)` | сказать своим рядом (15 м) слово и место |
| `self.mark("red")` | оставить запах: `"red"`, `"blue"`, `"green"`, `"yellow"` |

**Энергия.** Когда энергии меньше 30 %, пчела **сама** летит домой и заправляется, а потом
начинает `loop()` сначала. Порог меняет улей: `self.set_home_energy(40)`.

## Улей (`class MyHive(Hive)`)

| Пишешь | Что это |
|---|---|
| `self.honey` | сколько мёда |
| `self.count(Collector)` | сколько сборщиков (и так же `Scout`, `Worker`) |
| `self.hatch(Collector)` | вывести пчелу; `True` — получилось (сборщик стоит 4 мёда, домашняя — 2) |
| `self.set_home_energy(30)` | ниже скольких % пчёлы летят домой сами (0 — никогда) |
| `self.set_refuel_energy(100)` | до скольких % они заправляются |
| `self.say(...)`, `self.heard` | говорить и слышать у летка |
| `self.wait(5)` | подождать 5 секунд |

## Как получается мёд

**цветок → сборщик `collect` → домой `go_home` (выгрузка сама) → домашние пчёлы → мёд**

1 нектар превращается в 0.5 мёда. Мёд тратится на заправку пчёл, еду домашних и новых пчёл.

## Готовые кусочки

**Простой сборщик:**

```python
class MyCollector(Collector):
    def loop(self):
        flower = self.nearest_flower(min_nectar=0.3) or self.explore()
        if flower:
            self.collect(flower)
        if self.is_full:
            self.go_home()
```

**Разведчик рассказывает про цветы:**

```python
class MyScout(Scout):
    def loop(self):
        flower = self.explore()
        if flower:
            self.go_home()                  # прилететь домой…
            self.say("flowers", flower)     # …и рассказать, где цветы
```

**Сборщик слушает разведчиков:**

```python
for m in self.heard:
    if m.word == "flowers":
        self.collect(m)                     # долететь к месту и собрать
```

**Улей выводит сборщиков, когда мёда много:**

```python
class MyHive(Hive):
    def loop(self):
        if self.honey > 30:
            self.hatch(Collector)
        self.wait(5)
```

## Если что-то пошло не так

| Видишь | Что случилось | Что делать |
|---|---|---|
| Красный крестик у строки, «Синтаксическая ошибка» | опечатка: забыл `:`, скобку или кавычку | нажми на ошибку — редактор покажет строку |
| «Ошибка отступа» | строки внутри `if`, `for`, `def` должны сдвигаться на 4 пробела | выровняй отступы (`Tab` — 4 пробела) |
| В логах `File "my_bees.py", line 25` и `NameError` / `AttributeError` | ошибка в 25-й строке: опечатка в имени | нажми на ссылку в логе и проверь имя |
| В логах «это данные пчелы, их можно только читать» | написал `self.pos = …` | придумай своё имя: `self.my_pos = …` |
| В логах «бюджет» или «бесконечный цикл без команд» | `while True:` без команды внутри | добавь в цикл команду или `self.wait(1)` |
| Пчёлы падают | закончилась энергия | не ставь улью `set_home_energy(0)` |
| Мёд не растёт | сборщики не возвращаются домой или домашним нечего есть | проверь `go_home()` и не трать весь мёд на `hatch` |

## Проект и серия

- **⬇ Экспорт проекта** (в редакторе) — скачать свой рой файлом `.swarm`, отдать другу или
  загрузить в меню.
- **📂 Открыть проект…** — открыть чужой `.swarm` как свой новый скрипт.
- В меню проект можно поставить в любой улей и нажать **▶ Смотреть матч**.
- **Серия…** — тот же матч 10 раз на разных картах и погоде. Таблица покажет, где рой
  проигрывает; «Смотреть худший» — открыть самый неудачный матч и понять почему.
- Открывай только проекты от тех, кому доверяешь: их код выполняется на твоём компьютере.
