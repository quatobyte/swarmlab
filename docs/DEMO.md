# Сценарий показа SwarmLab (5–7 минут)

Сценарий повторяет PRD §3. Всё — на ноутбуке со встроенной графикой, без интернета.

## За день до показа (15 минут)

1. Обновить код и окружение, убедиться, что всё зелёное:

   ```powershell
   cd D:\Files\Projects\swarmlab
   .\.venv\Scripts\Activate.ps1
   python -m pytest -q
   ```

2. Записать **запасной реплей** — тот же матч, что будет на показе:

   ```powershell
   swarmlab run configs/matches/demo.yaml --headless
   swarmlab replay replays/demo-s42.swr
   ```

   В конце — таблица счёта и `хеш … совпадает`. Скопировать файл в надёжное место: `Copy-Item replays\demo-s42.swr $HOME\Desktop\`.
   Запустить ещё раз и сравнить хеш — он должен совпасть (это пригодится на показе).

3. `swarmlab bench` — убедиться, что для этой машины рекомендован профиль `medium` (RTF ≥ 1).

4. Подготовить **свой скрипт**: `swarmlab serve --open` → «✎ Редактор кода» → `my_bees.py`. Это копия шаблона, она уже работает. Заранее выбрать, какую строку поменять на показе (см. шаг 6), и один раз прогнать.

5. Отключить уведомления Windows и обновления, поставить питание «Максимальная производительность», зарядку — в розетку.

## Перед показом (2 минуты)

- PowerShell в папке проекта, `.venv` активирован.
- `swarmlab serve --open` — браузер открыт на лобби, вкладка развернута на весь экран (F11).
- Второе окно PowerShell — для запасного плана.
- Открыт `examples/bees/my_bees.py` в редакторе браузера (проверить, что сохранён без ошибок).

## Показ

### 1. Что это (30 с)

**Сказать:** «SwarmLab — симулятор роя. Мы не управляем пчёлами мышкой: ученик пишет на Python, как ведёт себя *одна* пчела, а поведение улья возникает само из сотни таких решений. Под капотом — настоящая физика MuJoCo, а у каждого улья свой процесс с кодом игрока».

### 2. 3D-мир (45 с)

**Сделать:** в лобби «Новый матч» → `demo.yaml` → «Запустить». Нажать `H` (обзор карты), покрутить камеру мышью.

**Показать:** рельеф, деревья и камни, три улья своих цветов, поляны цветов (яркость = нектар). Мир строится по seed: тот же seed — тот же мир.

### 3. Мой скрипт против двух примеров (1 мин)

**Сделать:** «Меню» → «✎ Редактор кода». В панели «Матч»: улей 1 — `my_bees.py`, 2 — `example_basic.py`, 3 — `example_smart.py`; шершни, пауки и погода включены; «Длительность» — 5 мин (по умолчанию 2 мин, а шершни прилетают с 60-й секунды). «▶ Запустить».

**Сказать:** «Три команды. Простой пример: сборщики летят к ближайшему цветку. Умный: разведчики находят поляны и пауков и рассказывают улью, улей пересказывает карту сборщикам, охранники ждут друг друга и нападают на шершня только втроём».

### 4. Рой в деле (1.5 мин)

**Сделать:** кликнуть по сборщику — камера следит за ним (`Esc` — отпустить). Клавиши `1`–`3` — к ульям. Скорость ×2, если сцена спокойная.

**Показать:**
- пчёлы летают в 3D, обходят деревья, расталкивают друг друга, их сносит ветер, видно дождь;
- сборщик набирает нектар над цветком и несёт домой, в HUD растёт нектар, затем мёд;
- в ленте событий — рождения новых пчёл, смена погоды;
- примерно с 60-й секунды — волны шершней с края карты; у умного улья охранники собираются в тепловой шар (в ленте «🔥 Тепловой шар»), шершень убегает или погибает; у простых ульев шершни ловят одиноких сборщиков и грабят мёд у летка.

**Сказать:** «Шершень охотится за пчёлами, рядом с которыми мало своих. Защита — тепловой шар, как у настоящих пчёл: охранники облепляют шершня».

### 5. Счёт (30 с)

**Показать:** HUD — мёд, нектар, пчёлы по типам у каждого улья; счёт обновляется в реальном времени. Победит улей, у которого к концу 5 минут больше мёда. Не обязательно ждать конца — можно сказать, что в балансном прогоне умный пример выигрывает почти всегда (`tools/balance.py`, таблица в `ROADMAP.md`).

### 6. Правка кода → новый матч (1.5 мин)

**Сделать:** вернуться в редактор, в `my_bees.py` в `MyForager.step` заменить `super().step(s)` на:

```python
        flower = s.nearest_flower(min_nectar=0.3)
        if flower is None and not s.me.in_hive and not s.me.is_full:
            self.fly_to(s.home.pos.x + 60, s.home.pos.y)   # все — на восток!
            return
        super().step(s)
```

«▶ Запустить» (`Ctrl+Enter`).

**Показать:** матч перезапустился, сборщики жёлтого улья ищут цветы одной струёй на восток. Ошибиться в коде не страшно: сделать опечатку — подсветится строка, сервер работает дальше. Бесконечный цикл улей просто пропускает ход: в логах предупреждение о бюджете времени.

**Сказать:** «Ребёнок правит только высокоуровневые команды: лететь, собирать, вернуться. Физику и автопилот берёт на себя симулятор».

### 7. Реплей (45 с)

**Сделать:** «Меню» → «Реплеи» → `demo-s42.swr` (или «Открыть файл .swr…» и файл с рабочего стола). Перемотать таймлайн на середину, скорость ×4.

**Сказать:** «Каждый матч пишется в реплей. Один seed и те же скрипты дают тот же хеш реплея — бит в бит. Это основа честных соревнований: результат можно перепроверить».

### Финал (15 с)

«Дальше — арена на сервере, рейтинг и тот же код агента для настоящих роботов. Ядро не знает про пчёл: следующие модули — карьерная техника и город».

## Если что-то пошло не так

| Что случилось | Что делать |
|---|---|
| Браузер тормозит, FPS < 20 (`F` — счётчик) | Качество графики → «Экономное»; скорость ×1. Не помогло — закрыть остальные вкладки и программы |
| Матч не запускается / ошибка в панели | «Стоп» → «▶ Запустить» ещё раз. Ошибка в `my_bees.py` — подсвеченная строка, исправить или выбрать в улье 1 `example_smart.py` |
| Сервер упал, страница не отвечает | Во втором окне: `swarmlab serve --open` (новый матч стартует без перезапуска ноутбука). Пока поднимается — рассказать про архитектуру |
| Браузер не открывается совсем | Показать реплей в окне MuJoCo: `swarmlab replay $HOME\Desktop\demo-s42.swr --mj-viewer --speed 2` — та же сцена, тот же матч |
| Не работает и MuJoCo-окно | Headless-матч: `swarmlab run configs/matches/demo.yaml --headless --duration 60 --report 10 --no-replay` — таблица счёта по ходу матча, события, RTF. Плюс `swarmlab replay $HOME\Desktop\demo-s42.swr` — итог и проверка хеша |
| Шершни не долетели до умного улья | Перемотать запасной реплей на 150–250 с: там волны по 2–3 шершня |
| Нужно показать детерминизм вживую | Два раза `swarmlab run configs/matches/demo.yaml --headless --duration 30 --replay a.swr` / `--replay b.swr` — хеши в последней строке совпадают |
