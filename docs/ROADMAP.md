## M0 — Скелет и одна пчела

**Входит:**
- Проверка окружения на Windows: версия Python (нужна ≥ 3.10), `.venv`, установка `mujoco`, `numpy`, `pydantic`, `pyyaml`, `msgpack`, `zstandard`, `fastapi`, `uvicorn`, `pytest`, `ruff`. Версии записать в `DECISIONS.md`.
- Структура пакетов по ARCHITECTURE §2, `pyproject.toml`, CLI `swarmlab` (`run`, заглушки `bench`, `replay`, `serve`).
- `core`: `config` (слияние defaults → profile → match → overrides, валидация), `rng` (реестр потоков), `clock`, контракты `Module`, `PhysicsBackend`.
- `bees`: генерация мира по seed (heightfield, деревья, камни, ульи, цветы как данные), MJCF-сборка, MuJoCo-бэкенд (`xfrc_applied`), векторный автопилот.
- Одна пчела облетает заданные точки (скриптом в модуле, без раннера).
- `swarmlab run configs/matches/m0.yaml --mj-viewer` и `--headless` (печатает RTF).

**Критерии приёмки:**
- [x] `pytest` и `ruff check` зелёные.
- [x] Тест: пчела достигает цели с точностью 0.5 м и останавливается без колебаний больше 0.3 м.
- [x] Тест: один seed → одинаковый мир (хеш массивов рельефа, цветов, препятствий); разные seed → разный.
- [x] Тест: `core` не импортирует `bees` и `mujoco` (проверка импорта или ruff-правило).
- [ ] Лео видит в MuJoCo-вьюере рельеф, деревья, ульи и летающую пчелу.

## M1 — Рой и физика

**Входит:** типы пчёл и параметры (BEES_SPEC §2), пул тел и парковка, маски столкновений, сопротивление, поле ветра, дождь, модель энергии и гибель, мягкие границы, просвет над рельефом, обход препятствий, пространственная сетка, вычисление `Sensors` (без связи с раннером), структуры сообщений и феромонов. Тестовый сценарий: 300 пчёл летают по случайным точкам.

**Критерии приёмки:**
- [x] Тест «толпа»: 100 пчёл летят в одну точку 60 с — расстояние между центрами всегда ≥ 0.9·(r1+r2). (`test_crowd_keeps_distance`: минимум 0.976)
- [x] Тест: пчела зависает над цветком — контактов с цветком нет, цветок не сдвигается. (`test_hover_over_flower_no_contact`)
- [x] Тест: крейсерские скорости и время полёта по типам в пределах ±15% от целей. (`test_cruise_speed_and_flight_time_within_15_percent`: 8.00/5.00/6.00 м/с, 300/240/180 с)
- [x] Тест: сборщик с полным грузом разгоняется медленнее пустого при той же команде. (`test_loaded_forager_accelerates_slower_same_command`, `test_cargo_mass_slows_acceleration_in_mujoco`)
- [x] Тест: при боковом ветре без коррекции пчелу сносит по ветру; автопилот компенсирует снос. (`test_crosswind_drifts_without_correction_autopilot_compensates`, `test_autopilot_flies_straight_across_wind`)
- [x] Тест: пчела с нулевой энергией падает и погибает, слот возвращается в пул. (`test_zero_energy_falls_dies_and_slot_returns_to_pool`)
- [x] Headless профиль «Средний» (300 пчёл) — RTF ≥ 1.0 на машине Лео (вывод `--headless` показан). (`m1_swarm.yaml`, 120 с, i3-8145U: RTF = 1.7–2.7 в разных прогонах)

## M7a — Блокирующие команды и процедуры в Python-API

**Входит:** `step()` с `yield` (DECISIONS 57–59); ожидание в `core`/раннере; `yield wait()` и `yield wait(секунды)`; потолок `command_timeout_s`; закрытие генератора при смерти и прерывании; `example_wait.py`; регрессия M1–M6; раздел PLAYER_API.md про `yield`. Значения по умолчанию — в `configs/bees/defaults.yaml`, секция `program:`.

**Критерии приёмки:**
- [ ] Тест: `ok = yield fly_to(точка)` возвращает `True` у достижимой цели и `False` у недостижимой за `command_timeout_s`.
- [ ] Тест: `step()` без `yield` даёт тот же результат, что до M7a (траектории, счёт, хеш реплея `demo.yaml`; различия объяснены в отчёте).
- [ ] Тест: смерть пчелы в ожидании вызывает `close()`, `finally` выполнен, новая пчела стартует программу с начала.
- [ ] Тест: `yield wait()` в цикле не вызывает срабатывания бюджета CPU на тик.
