## M0 — Скелет и одна пчела

**Входит:**
- Проверка окружения на Windows: версия Python (нужна ≥ 3.10), `.venv`, установка `mujoco`, `numpy`, `pydantic`, `pyyaml`, `msgpack`, `zstandard`, `fastapi`, `uvicorn`, `pytest`, `ruff`. Версии записать в `DECISIONS.md`.
- Структура пакетов по ARCHITECTURE §2, `pyproject.toml`, CLI `swarmlab` (`run`, заглушки `bench`, `replay`, `serve`).
- `core`: `config` (слияние defaults → profile → match → overrides, валидация), `rng` (реестр потоков), `clock`, контракты `Module`, `PhysicsBackend`.
- `bees`: генерация мира по seed (heightfield, деревья, камни, ульи, цветы как данные), MJCF-сборка, MuJoCo-бэкенд (`xfrc_applied`), векторный автопилот.
- Одна пчела облетает заданные точки (скриптом в модуле, без раннера).
- `swarmlab run configs/matches/m0.yaml --mj-viewer` и `--headless` (печатает RTF).

**Критерии приёмки:**
- [x] `pytest` и `ruff check` зелёные.
- [x] Тест: пчела достигает цели с точностью 0.5 м и останавливается без колебаний больше 0.3 м.
- [x] Тест: один seed → одинаковый мир (хеш массивов рельефа, цветов, препятствий); разные seed → разный.
- [x] Тест: `core` не импортирует `bees` и `mujoco` (проверка импорта или ruff-правило).
- [ ] Лео видит в MuJoCo-вьюере рельеф, деревья, ульи и летающую пчелу.

## M1 — Рой и физика

**Входит:** типы пчёл и параметры (BEES_SPEC §2), пул тел и парковка, маски столкновений, сопротивление, поле ветра, дождь, модель энергии и гибель, мягкие границы, просвет над рельефом, обход препятствий, пространственная сетка, вычисление `Sensors` (без связи с раннером), структуры сообщений и феромонов. Тестовый сценарий: 300 пчёл летают по случайным точкам.

**Критерии приёмки:**
- [ ] Тест «толпа»: 100 пчёл летят в одну точку 60 с — расстояние между центрами всегда ≥ 0.9·(r1+r2).
- [ ] Тест: пчела зависает над цветком — контактов с цветком нет, цветок не сдвигается.
- [ ] Тест: крейсерские скорости и время полёта по типам в пределах ±15% от целей.
- [ ] Тест: сборщик с полным грузом разгоняется медленнее пустого при той же команде.
- [ ] Тест: при боковом ветре без коррекции пчелу сносит по ветру; автопилот компенсирует снос.
- [ ] Тест: пчела с нулевой энергией падает и погибает, слот возвращается в пул.
- [ ] Headless профиль «Средний» (300 пчёл) — RTF ≥ 1.0 на машине Лео (вывод `--headless` показан).

## M2 — Код игрока и экономика

**Входит:** протокол (msgpack + длина кадра), `swarmlab.runner`, `ProcessLink`, параллельная рассылка, CPU-бюджет, жёсткий таймаут, перезапуск раннера, изоляция исключений по пчёлам; `bees/api.py` (классы, команды, `Sensors`), `hive_step`, домашние пчёлы; экономика (BEES_SPEC §4); `examples/bees/template.py`, `example_basic.py`, черновик `example_smart.py`.

**Критерии приёмки:**
- [ ] Тест: скрипт с `while True` — матч идёт, улей пропускает тики, после 3 подряд раннер перезапускается.
- [ ] Тест: исключение в `step()` одной пчелы — она зависает, остальные работают, трассировка в логе.
- [ ] Тест: превышение бюджета фиксируется в статистике.
- [ ] Юнит-тесты экономики: убывающая отдача переработки, курс 1→0.5, цена и время выведения, питание.
- [ ] Инвариант-тест: мёд в любой момент ≤ стартовый + 0.5·переработанный нектар (мёд из воздуха не появляется).
- [ ] `example_basic.py` headless за 120 с увеличивает мёд улья.
- [ ] Всё работает на Windows (spawn), а не только в Linux.

## M3 — Враги, матч, реплеи, профили

**Входит:** погода (BEES_SPEC §6), шершни и тепловой шар, грабёж, пауки, переключатели в конфиге; счёт, выбывание, конец матча, события; реплей `.swr` (запись, чтение, хеш), `swarmlab replay <file> --mj-viewer`; профили и `swarmlab bench`.

**Критерии приёмки:**
- [ ] Тест детерминизма: `demo.yaml` дважды → одинаковый хеш реплея.
- [ ] Тест: `enabled: false` полностью убирает шершней / пауков / погоду.
- [ ] Сценарный тест: 3 охранника окружают шершня → шершень погибает или улетает.
- [ ] Статистический тест пауков (фиксированный seed): доля гибелей в ожидаемых пределах.
- [ ] `swarmlab run configs/matches/demo.yaml --headless` доходит до конца и печатает таблицу счёта.
- [ ] `swarmlab bench` печатает RTF по профилям и рекомендацию.

## M4 — Сервер и Three.js-вьюер

**Входит:** FastAPI (ARCHITECTURE §7), матч в отдельном процессе, WS-стрим (статическая сцена + кадры), `web/` без сборщика: рельеф, деревья, камни, ульи цветами команд, цветы (instanced, яркость = нектар), пчёлы InstancedMesh по типам и командам, шершни, интерполяция, орбитальная камера и «следить за пчелой», HUD (мёд, нектар, численность по типам, погода, время), лента событий, лёгкий эффект дождя; режим реплея с таймлайном, перемоткой и скоростью.

**Критерии приёмки:**
- [ ] `swarmlab serve` → браузер → живой матч `demo.yaml`.
- [ ] ≥ 30 FPS на iGPU Лео при профиле «Средний».
- [ ] Реплей из файла воспроизводится, перемотка работает.
- [ ] Остановка вкладки браузера не ломает сервер; новый матч стартует без перезапуска сервера.
- [ ] Лео прошёл ручной чек-лист из промта M4.

## M5 — Редактор кода в браузере

**Входит:** редактор (без сборщика, офлайн, vendored), файл `my_bees.py`, сохранение, перезапуск матча, выбор соперников, переключатели врагов и погоды, профиль, seed; вывод логов и ошибок раннера по каждому улью.

**Критерии приёмки:**
- [ ] Правка кода в браузере → перезапуск → поведение пчёл меняется.
- [ ] Синтаксическая ошибка показывается в UI с номером строки, сервер не падает.
- [ ] Лео прошёл ручной чек-лист из промта M5.

## M6 — Буфер и демо

**Входит:** исправление багов, доведение `example_smart.py`, балансный прогон (10 seed’ов headless: smart стабильно сильнее basic, мёд не растёт неограниченно), `README.md` с установкой на Windows, сценарий показа (PRD §3).

**Критерии приёмки:**
- [ ] Демо-сценарий PRD §3 проходит на машине Лео от начала до конца.
- [ ] Все тесты зелёные.
- [ ] Установка по README из чистой копии работает.
