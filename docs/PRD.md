# PRD — SwarmLab (ядро + модуль пчёлок)

Версия 0.1 · 12.10.2026 · Автор: Лео

## 1. Что это

SwarmLab — модульный 3D-симулятор роевых (многоагентных) систем. Пользователь не управляет агентами напрямую: он пишет на Python логику каждого агента и наблюдает, как из локальных решений возникает коллективное поведение.

Платформа состоит из ядра и модулей:

| Модуль | Назначение | Статус |
|---|---|---|
| **Swarm Logic (пчёлки)** | Обучение детей и подростков программированию роевых систем + соревнования | Строится сейчас |
| Карьер | Физический симулятор тяжёлой карьерной техники в роевых системах (горнодобыча) | После пчёлок, отдельное обсуждение |
| Город | Курьеры, общественный транспорт, распределение трафика; десятки тысяч агентов | После пчёлок, отдельное обсуждение |
| Мост к роботам | Тот же код агента управляет реальными роботами собственной разработки | После появления железа |

## 2. Пользователи

- **Ученик 10–17 лет** — пишет Python-код пчёл, учится алгоритмам (конечные автоматы, поиск, распределение ролей, коммуникация), соревнуется.
- **Преподаватель / организатор соревнований** — задаёт сценарии, профили, включает/выключает врагов и погоду, сравнивает решения.
- **Разработчик (Лео)** — развивает платформу и модули.

## 3. Цели до 20.10.2026 (демо)

Работающая локальная 3D-песочница пчёлок + документы платформы.

Сценарий демонстрации:
1. Запуск на ноутбуке со встроенной графикой.
2. Открыть браузер → 3D-сцена: рельеф, деревья, цветы, 3 улья.
3. Мой скрипт против двух скриптов-примеров, шершни и погода включены.
4. Пчёлы летают в 3D, сталкиваются, несут нектар, улей перерабатывает его в мёд и выводит новых пчёл, охранники окружают шершней.
5. Счёт в реальном времени, победитель по мёду за N тиков.
6. Повтор матча из файла реплея.
7. Показать, как код игрока меняется в редакторе и матч перезапускается (если M5 успели).

### Критерии успеха демо

- Профиль «Средний» (3 улья × 100 пчёл, 300×300 м) идёт не медленнее реального времени на машине разработчика.
- Один seed + те же скрипты → одинаковый хеш реплея.
- Бесконечный цикл в скрипте игрока не вешает симуляцию: улей пропускает ход, матч идёт дальше.
- Ребёнок может изменить поведение пчёл, правя только высокоуровневые команды в шаблоне с русскими комментариями.

## 4. Объём работ до 20.10

**Входит:**
- Ядро: цикл симуляции с тремя частотами, конфиги и профили, seed-RNG, реплеи, раннер кода игроков с CPU-бюджетом, headless CLI, бенчмарк, контракт модулей.
- Пчёлки: 3D-физика на MuJoCo, 4 типа пчёл, автопилот, сенсоры, связь и феромоны, экономика улья, шершни, пауки, погода, счёт.
- Локальный FastAPI-сервер + Three.js-вьюер (живой режим и реплей).
- Редактор кода в браузере (M5, режется первым при отставании).
- Скрипты-примеры и шаблон для игрока.

**Не входит (после 20.10):**
- Сетевая соревновательная арена, аккаунты, рейтинг, контейнерная изоляция на сервере.
- Браузерная песочница на Pyodide.
- Чертежи, маркетплейс, дерево прокачки, Idle-механики.
- Болезни, другие хищники, сезоны.
- Модули «Карьер» и «Город», мост к роботам — только архитектурные заготовки (контракты).

## 5. Режимы (целевая картина)

| Режим | Где выполняется код игрока | Параметры среды | Когда |
|---|---|---|---|
| Песочница | Локально у пользователя | Пользователь меняет всё | до 20.10 |
| Локальный матч | Локально, несколько скриптов | Конфиг матча | до 20.10 |
| Арена | На сервере SwarmLab, в контейнерах | Скрытые и динамические, задаёт сервер | после 20.10 |

Для модулей «Карьер» и «Город» код выполняется на наших мощностях (сервер или компьютер, на котором запущен симулятор).

## 6. Нефункциональные требования

- **Масштабируемость:** число ульев, пчёл, врагов и размер карты задаются профилем; чем мощнее машина, тем больше профиль. Сервер масштабируется числом параллельных матчей (по процессу на матч).
- **Слабое железо:** профиль «Средний» — на ноутбуке с iGPU Intel и 4+ ядрами CPU.
- **Детерминизм и воспроизводимость** — основа честных соревнований и отладки.
- **Безопасность:** код игрока изолирован процессом (локально) и контейнером (на сервере, позже).
- **Платформа разработки:** Windows; сервер в будущем — Linux.
- **Язык:** интерфейс и документация на русском; API на английском.
