# API игрока: рой пчёл

Справочник по всему, что доступно скрипту игрока. Источник истины — `src/swarmlab/bees/api.py`:
если документ и код расходятся, прав код (и документ надо поправить). Те же сведения показывает
редактор в браузере: подсказки по `.` и `Ctrl+Пробел` генерируются из `api.py`
(`tools/gen_api_hints.py`). Короткая версия для школьников — [`CHEATSHEET.md`](CHEATSHEET.md).
Правила мира и числа по умолчанию — [`BEES_SPEC.md`](BEES_SPEC.md) и `configs/bees/defaults.yaml`.

## 1. Как устроен скрипт

```python
from swarmlab.bees.api import Forager, Guard, Hive, HouseBee, HouseSensors, Scout, Sensors


class MyForager(Forager):          # свой класс для типа пчёл
    def step(self, s: Sensors):    # вызывается каждый тик у каждой пчелы этого типа
        ...


def hive_step(hive: Hive):         # необязательно: решения улья, раз в тик
    ...
```

- **Тик** — шаг решений, 10 раз в секунду. На каждом тике у каждой живой пчелы вызывается
  `step(self, s)`, затем один раз `hive_step(hive)`.
- Скрипт находит классы сам: первый в файле подкласс `Scout`, `Forager`, `Guard`, `HouseBee`.
  Нет своего класса или он не переопределяет `step()` — поведение «по умолчанию».
  Внутри своего `step()` можно вызвать `super().step(s)`, тогда тоже сработает поведение по умолчанию.
- **Память.** Пчела — обычный объект Python: что сохранено в `self`, доживёт до следующего тика.
  Улей помнит словарь `hive.memory`. Если раннер перезапускается (завис, упал), память теряется.
- **Команды.** Внутри `step()` пчела вызывает методы-команды (`self.fly_to(...)`). Из команд
  движения за тик действует **последняя**. `signal` и `mark` добавляются к движению. Если пчела
  ничего не вызвала, она продолжает прошлую команду.
- **Видимость.** Сенсоры показывают только то, что рядом (радиус обзора типа пчелы), а не всю карту.
- **Единицы:** метры, секунды, джоули; нектар и мёд — условные единицы (ед.). Ось `z` смотрит вверх,
  центр карты — `(0, 0)`.
- **Время.** На все `step()` улья за тик даётся **20 мс** (бюджет, `runner.budget_ms`). Превысил —
  команды тика отброшены, в логе предупреждение. Нет ответа 200 мс (`hard_timeout_ms`) — тик
  пропущен; 3 пропуска подряд — раннер перезапускается; после 20 перезапусков улей отключается.
- **Ошибки.** Исключение в `step()` одной пчелы не трогает остальных: пчела зависает на этом тике,
  трассировка с номером строки уходит в лог улья (повторы одной и той же ошибки — со счётчиком).
- **`print()`** пишет в лог улья: `logs/<матч>/hive<N>.log`, а в редакторе — панель «Логи».
- Модуль `random` уже засеян seed’ом матча — один seed даёт тот же матч.

## 2. Сенсоры летающей пчелы — `Sensors`

| Поле / метод | Тип | Что это |
|---|---|---|
| `tick` | `int` | номер тика (10 в секунду) |
| `time` | `float` | время матча, с |
| `me` | `Me` | я сама (см. ниже) |
| `home` | `Home` | мой улей: `pos` (леток), `dir` (направление на леток, длина 1), `dist` |
| `ground_z` | `float` | высота земли подо мной, м |
| `airspeed` | `Vec` | ветер в моей точке, м/с |
| `weather` | `str` | погода: `"clear"`, `"windy"`, `"rain"` |
| `flowers` | `list[Flower]` | цветы в радиусе обзора, ближние первыми |
| `bees` | `list[BeeInfo]` | пчёлы рядом (свои и чужие) |
| `enemies` | `list[Enemy]` | враги рядом (шершни) |
| `obstacles` | `list[Obstacle]` | препятствия рядом (деревья, камни) |
| `messages` | `list[Message]` | сообщения от своих пчёл (с прошлого тика) |
| `pheromones` | `Pheromones` | запахи своего улья вокруг меня |
| `nearest_flower(min_nectar=0.0)` | `Flower \| None` | ближайший цветок, где нектара не меньше `min_nectar` |
| `nearest_enemy()` | `Enemy \| None` | ближайший враг |

### `Me` — я сама

| Поле | Тип | Что это |
|---|---|---|
| `id` | `int` | номер пчелы (не меняется) |
| `kind` | `str` | `"scout"`, `"forager"`, `"guard"` |
| `pos`, `vel` | `Vec` | где я (м) и моя скорость (м/с) |
| `energy`, `energy_max` | `float` | запас энергии и полный запас, Дж (0 — пчела падает и гибнет) |
| `energy_percent` | `float` | энергия в процентах, 0–100 |
| `cargo`, `cargo_max` | `float` | несу нектара и сколько влезает (у сборщика 1.5, у остальных 0) |
| `is_full` | `bool` | груз полный — пора домой |
| `in_hive` | `bool` | я в улье (там заправка и выгрузка) |
| `alive` | `bool` | жива ли |

### Что видно вокруг

| Класс | Поля |
|---|---|
| `Flower` | `id` (его передают в `collect`), `pos`, `rel_pos` (относительно меня), `dist`, `nectar` (до 3 ед.), `spider` — паук на цветке: `True`/`False`, если видно (разведчик ближе 4 м), иначе `None` |
| `BeeInfo` | `id`, `kind`, `team` (номер улья), `friend` (из моего улья), `pos`, `rel_pos`, `dist`, `vel` |
| `Enemy` | `id` (его передают в `intercept`), `kind` (`"hornet"`), `pos`, `rel_pos`, `dist`, `vel` |
| `Obstacle` | `pos` (ближайшая точка оси), `rel_pos`, `dist` (до оси), `radius` (до поверхности — `dist - radius`) |
| `Message` | `from_id` (кто отправил; `HIVE_ID = -1` — сам улей), `pos`, `rel_pos`, `values` (до 8 чисел) |
| `Pheromones` | `strength(channel)` — сила запаха под пчелой; `direction(channel)` — `Vec`, куда запах сильнее; сырые `values[i][j][c]` (клетки 3×3) и `gradient[c]` |

### `Vec` — точка или направление

`Vec(x, y, z=0)`; поля `x`, `y`, `z`. Работают `+`, `-`, `* число`, `/ число`, унарный `-`.
Методы: `length()`, `length_xy()` (без высоты), `normalized()`, `dist(p)`, `dist_xy(p)`.
Точку можно передать в команду целиком: `self.fly_to(*flower.pos)`.

## 3. Команды летающих пчёл

Общие для разведчика, сборщика и охранника (класс `Bee`):

| Команда | Что делает |
|---|---|
| `fly_to(x, y, z=None, speed=None, avoid=True)` | лететь к точке. `z` — абсолютная высота (по умолчанию 5 м над землёй), `speed` — м/с (по умолчанию крейсерская), `avoid=False` — не облетать деревья и соседей |
| `fly_dir(dx, dy, dz=0, speed=None)` | лететь в направлении, пока не скажут другое (длина вектора неважна, `(0, 0, 0)` — ошибка) |
| `hover()` | зависнуть на месте (в улье — остаться внутри) |
| `go_home()` | лететь к летку и войти в улей |
| `leave_hive()` | вылететь из улья |
| `signal(*values)` | сообщение до 8 чисел своим в радиусе 15 м; дойдёт на следующем тике (`s.messages`) |
| `mark(channel, amount=1.0)` | оставить запах канала 0–3 в клетке под собой; слабеет вдвое за минуту, чувствуют только свои |
| `thrust(fx, fy, fz)` | только при `advanced_control: true`: прямая сила тяги, Н, автопилот выключен |

Если пчела в улье, `fly_to`, `fly_dir`, `collect`, `intercept` и `thrust` сначала выводят её наружу.

### Типы пчёл

| Тип | Класс | Скорость | Обзор | Полёт на полном баке | Свои команды |
|---|---|---|---|---|---|
| Разведчик | `Scout` | ≈8 м/с | 25 м | ≈5 мин | — (нектар не носит, замечает пауков ближе 4 м) |
| Сборщик | `Forager` | ≈5 м/с | 8 м | ≈4 мин | `collect(flower)` — подлететь к цветку и набирать нектар (0.25 ед./с, пока груз не полный или цветок не пуст); `unload()` — выгрузить всё на склад (только в улье) |
| Охранник | `Guard` | ≈6 м/с | 12 м | ≈3 мин | `intercept(target)` — преследовать врага с упреждением; двое и больше рядом с шершнем — «тепловой шар» |

`collect`, `intercept` принимают объект (`flower`, `enemy`) или его номер (`flower.id`).

## 4. Домашние пчёлы — `HouseBee`

Не летают, живут в улье. `step(self, s: HouseSensors)`.

| Сенсор | Что это |
|---|---|
| `s.me` | `HouseMe`: `id`, `kind` (`"house"`), `task` — текущая задача (`"rest"`, `"process"`, `"nurse"`) |
| `s.hive_nectar`, `s.hive_honey` | нектар и мёд на складе, ед. |
| `s.breeding_queue` | очередь выведения: список `Larva(kind, left_s)` |
| `s.counts` | сколько пчёл (`Counts`, см. ниже) |
| `s.tick`, `s.time` | тик и время матча |

Команды: `process()` — перерабатывать нектар в мёд (1 ед. нектара → 0.5 ед. мёда), `nurse()` —
ухаживать за личинками (больше нянек — быстрее выведение), `rest()` — отдыхать. Каждая домашняя
пчела ест 0.002 ед. мёда в секунду; без мёда не работает.

## 5. Улей — `hive_step(hive: Hive)`

| Поле / команда | Что это |
|---|---|
| `tick`, `time` | тик и время матча |
| `honey`, `nectar` | мёд и нектар на складе, ед. |
| `counts` | `Counts`: `scout`, `forager`, `guard`, `house` — живые пчёлы по типам; `in_hive`, `flying` — словари `{тип: число}`; `total()` |
| `queue` | очередь выведения (`list[Larva]`) |
| `max_bees` | больше этого пчёл (с личинками) быть не может |
| `costs` | цена выведения в мёде: `costs["forager"]` |
| `messages` | сообщения своих пчёл рядом с летком |
| `memory` | словарь — память улья между тиками |
| `breed(kind, n=1)` | вывести `n` пчёл типа `"scout"`, `"forager"`, `"guard"`, `"house"`; мёд списывается сразу. Не хватает мёда или улей полон — личинка не ставится (сообщение в лог) |
| `cancel_breeding(kind)` | отменить последнюю личинку типа `kind` (мёд вернётся) |
| `signal(*values)` | сообщение до 8 чисел всем своим в радиусе 15 м от летка (`from_id == HIVE_ID`) |

Цены и время выведения по умолчанию (`configs/bees/defaults.yaml`, `economy.breeding`):
разведчик 3 ед. / 30 с, сборщик 4 / 30 с, охранник 6 / 45 с, домашняя 2 / 20 с;
время делится на √(число нянек). На старте у улья 20 ед. мёда и 5 разведчиков,
15 сборщиков, 5 охранников, 10 домашних.

## 6. Экономика и победа

Сборщик набирает нектар на цветке → несёт в улей → `unload()` → домашние `process()` превращают
1 ед. нектара в 0.5 ед. мёда. Мёд тратится на заправку пчёл в улье (1 ед. = 4000 Дж), еду домашних
и новых пчёл. Побеждает улей, у которого в конце матча больше мёда.

## 7. Враги

- **Шершни** (если включены): прилетают волнами с края карты, охотятся на одиночных пчёл, грабят
  мёд у летка. Охранники рядом с шершнем наносят ему урон; шершень может погибнуть или улететь.
- **Пауки** (если включены): сидят на части цветов и кусают сборщиков, которые собирают нектар.
  Разведчик ближе 4 м видит паука: `flower.spider == True`.
- **Погода**: ясно, ветер (сносит пчёл, `s.airspeed`), дождь (капли давят вниз и тормозят — полёт тяжелее и дороже по энергии).

Каждого врага и погоду можно выключить в матче (`enemies.hornets.enabled: false` и т. д.) или
переключателями в панели «Матч» редактора.

## 8. Ограничения для скрипта

- Скрипт выполняется в отдельном процессе-раннере; `input()` не работает, `print()` идёт в лог.
- Неверные аргументы команд (`None`, `NaN`, не число, неизвестный тип пчелы) — исключение
  `TypeError` или `ValueError` с понятным текстом; пчела зависает на этом тике.
- Скрипт может импортировать соседние файлы из своей папки и стандартную библиотеку.
- В редакторе можно править только свои файлы в `examples/bees/`; `template.py` и `example_*.py`
  — справочные, их копируют через «Сохранить как».
