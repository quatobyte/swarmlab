# API игрока: рой пчёл

Справочник по всему, что доступно скрипту игрока. Источник истины — `src/swarmlab/bees/api.py`:
если документ и код расходятся, прав код (и документ надо поправить). Те же сведения показывает
редактор в браузере: подсказки по `.` и `Ctrl+Пробел` генерируются из `api.py`
(`tools/gen_api_hints.py`). Короткая версия для школьников — [`CHEATSHEET.md`](CHEATSHEET.md).
Правила мира и числа по умолчанию — [`BEES_SPEC.md`](BEES_SPEC.md) и `configs/bees/defaults.yaml`.

Игра учит **мультиагентной системе**: у каждой пчелы один и тот же код, она видит только то, что
рядом, и договаривается с соседями словами (`say`/`heard`) и запахами (`mark`/`smell`). Всё, что
не про это (выгрузка нектара, работа домашних пчёл, вылет из улья, заправка при низкой энергии),
происходит само (DECISIONS №82, №84–87).

## 1. Как устроен скрипт

```python
from swarmlab.bees.api import Collector, Hive, Scout


class MyScout(Scout):
    def loop(self):                  # что делает каждый разведчик — снова и снова
        flower = self.explore()      # искать цветы; строка закончится, когда найдёт или долетит
        if flower:
            self.go_home()           # ждёт, пока пчела войдёт в улей
            self.say("flowers", flower)


class MyCollector(Collector):
    def loop(self):
        ...


class MyHive(Hive):                  # необязательно: решения улья
    def loop(self):
        ...
```

- **`loop()`** — «что делать». Игра выполняет его снова и снова, по кругу, у каждой живой пчелы
  своего типа и у улья. Один круг — не чаще раза за тик (10 раз в секунду): если в `loop()` нет
  команд, которые ждут, следующий круг начнётся на следующем тике.
- **Команды движения ждут сами.** `self.fly_to(flower)` закончится, когда пчела долетит (или не
  успеет за 60 с). Поэтому код читается как рассказ: «найди, собери, лети домой». `yield` не нужен.
- Скрипт находит классы сам: первый в файле подкласс `Scout`, первый — `Collector`, первый — `Hive`.
  Нет своего класса — поведение «по умолчанию». В своём `loop()` можно вызвать `super().loop()`.
- **Всё через `self`.** Данные пчелы — `self.pos`, `self.energy`, `self.flowers`… — только для
  чтения: `self.pos = …` даёт понятную ошибку. Свою память храни под своими именами:
  `self.my_flower = flower` — доживёт до следующего круга. Можно завести `__init__(self)` без
  параметров: данные пчелы в нём уже доступны. Если раннер перезапускается (завис), память теряется.
- **Видимость.** Пчела видит только то, что рядом (радиус обзора типа), а не всю карту.
- **Единицы:** метры, секунды; энергия — проценты своего бака. Центр карты — `(0, 0)`.
- **Время.** На код улья за тик даётся **20 мс** (бюджет, `runner.budget_ms`). Пока пчела ждёт
  команду, её код не выполняется и бюджет не тратит. Превысил — команды тика отброшены, в логе
  предупреждение. Нет ответа 200 мс (`hard_timeout_ms`, например бесконечный цикл без команд) —
  тик пропущен; 3 пропуска подряд — раннер перезапускается; после 20 перезапусков улей отключается.
- **Ошибки.** Исключение в `loop()` одной пчелы не трогает остальных: трассировка с номером строки
  уходит в лог улья (повторы — со счётчиком), пчела останавливается, на следующем тике её `loop()`
  начинается сначала.
- **Смерть.** Пчела погибла, пока ждала, — её `loop()` прерывается, выполняется `finally`, если он
  есть. Новая пчела начинает `loop()` с начала. В конце матча `finally` тоже выполняется.
- **`print()`** пишет в лог улья: `logs/<матч>/hive<N>.log`, а в редакторе — панель «Логи».
- Модуль `random` уже засеян seed’ом матча — один seed даёт тот же матч.

## 2. Что знает пчела (только читать)

| Данные | Тип | Что это |
|---|---|---|
| `pos` | `Point` | где я |
| `energy` | `float` | энергия, % своего бака: 100 — полный, 0 — пчела падает и гибнет |
| `max_energy` | `float` | размер моего бака, Дж — у каждой пчелы свой (±20 % от обычного) |
| `nectar` | `float` | сколько нектара несу (сборщик — до 1.5) |
| `is_full` | `bool` | груз полный — пора домой |
| `at_home` | `bool` | я дома, в улье |
| `home` | `Point` | вход в мой улей |
| `flowers` | `list[Flower]` | цветы, которые вижу, ближние первыми |
| `nearest_flower(min_nectar=0)` | `Flower \| None` | ближайший цветок, где нектара не меньше `min_nectar` |
| `bees` | `list[OtherBee]` | пчёлы, которых вижу (свои и чужие) |
| `time` | `float` | сколько секунд идёт матч |
| `heard` | `list[Message]` | что я услышала (§4) |
| `smell(color)` | `float` | запах цвета `color` подо мной (0 — не пахнет) |
| `smell_way(color)` | `Point \| None` | точка в 5 м от меня, где запах сильнее; `None` — запаха рядом нет |

| Класс | Поля |
|---|---|
| `Flower` | `pos`, `nectar` (до 3), `distance` (от меня, м), `spider` — паук на цветке: `True`/`False`, если видно (разведчик ближе 4 м по горизонтали), иначе `None` |
| `OtherBee` | `pos`, `friend` (из моего улья), `distance` |
| `Message` | `word` (слово), `where` (место, которое назвали, или `None`), `from_where` (откуда сказали) |
| `Point` | `x`, `y` (и высота `z`); `+`, `-`, `* число`; `distance(p)` — расстояние по карте до точки, цветка или пчелы |

## 3. Команды

**Цель** команды движения — цветок, пчела, сообщение (его место; если места нет — откуда
сказали), точка или два числа: `self.fly_to(flower)`, `self.fly_to(msg)`, `self.fly_to(10, 20)`.
У всех команд движения есть необязательный `speed=` (м/с, для продвинутых): `self.go_home(speed=3)`.

| Команда | Ждёт | Возвращает |
|---|---|---|
| `fly_to(цель)` | пока долетит | `True` — долетела; `False` — не успела за 60 с |
| `search(цель)` | пока долетит или увидит цветок с нектаром | этот цветок или `None` |
| `explore()` | то же, что `search` к случайной точке вокруг дома (15–60 м) | цветок или `None` |
| `collect(цветок или место)` | пока наберёт нектар (только `Collector`) | `True` — груз полный; `False` — цветок опустел, у места нет цветка с нектаром, 60 с |
| `go_home()` | пока войдёт в улей (нектар выгрузится сам) | `True` |
| `refuel(уровень=100)` | дома, пока энергия не дойдёт до уровня; не дома — сначала летит домой | `True` / `False` (нет мёда — не заправиться за 60 с) |
| `wait(секунды=0)` | столько секунд игрового времени (`wait()` — до следующего тика) | — |
| `stop()` | не ждёт: остановиться и висеть (дома — остаться в улье) | — |
| `say(слово, место=None)` | не ждёт: сказать своим (§4) | — |
| `mark(цвет)` | не ждёт: оставить запах `"red"`, `"blue"`, `"green"` или `"yellow"` | — |

- Из улья `fly_to`, `search`, `explore`, `collect` сами выводят пчелу наружу.
- «Долетела» — ближе 0.5 м к цели и медленнее 0.3 м/с (`program.arrive_tolerance`,
  `program.arrive_max_speed`); таймаут — `program.command_timeout_s` (60 с игрового времени).
- `collect(место)`: подлетев к месту, сборщик выбирает ближайший к нему цветок с нектаром
  (не дальше 8 м от места, `program.collect_place_radius`) и собирает с него.
- Цветок «с нектаром» для `search`/`explore`/`collect(место)` — нектара не меньше 0.3
  (`program.search_min_nectar`).

### Энергия и автовозврат

Когда энергии становится меньше порога (по умолчанию **30 %**), пчела **сама** летит домой: текущая
команда возвращает `False`, команды движения не выполняются (сразу `False`), пока она не
заправится дома до уровня (по умолчанию 100 %). После этого её `loop()` начинается **сначала**
(старый круг прерывается, `finally` выполняется). Порог и уровень меняет улей:
`set_home_energy(…)`, `set_refuel_energy(…)`. Порог 0 — автовозврата нет, следи сам.

Заправка дома идёт всегда, пока пчела в улье; сколько ждать — решает игрок (`refuel(80)`).

### Типы пчёл

| Тип | Класс | Скорость | Обзор | Полёт на полном баке | Особое |
|---|---|---|---|---|---|
| Разведчик | `Scout` | ≈8 м/с | 25 м | ≈5 мин | замечает пауков ближе 4 м; нектар не носит |
| Сборщик | `Collector` | ≈5 м/с | 8 м | ≈4 мин | `collect`; с грузом тяжелее и медленнее |
| Домашняя | `Worker` | — | — | — | живёт в улье, кода нет: делает мёд и растит личинки |

## 4. Связь: `say` и `heard`

- `self.say("flowers", flower)` — слово (до 20 букв) и, если нужно, место. Слышат свои пчёлы в
  радиусе **15 м** на следующем тике. Пчёлы в улье слышат у летка; улей слышит, если сказано в
  15 м от летка. Чужие ульи не слышат. За тик — не больше 4 сообщений.
- `self.heard` копит услышанное: сообщение видно с момента, когда пришло, до конца **следующего**
  круга `loop()`. Пока пчела ждёт команду, ничего не теряется. От каждого отправителя —
  последнее сообщение с каждым словом.

```python
for m in self.heard:
    if m.word == "flowers":
        self.collect(m)        # долететь к месту из сообщения и собрать
```

- Запахи: `self.mark("red")` — запах в клетке 2 м под пчелой, слабеет вдвое за минуту, чуют только
  свои. `self.smell("red")` — сила здесь, `self.smell_way("red")` — куда лететь, чтобы сильнее.

## 5. Улей — класс `Hive`

У улья тот же `loop()` по кругу.

| Данные / команда | Что это |
|---|---|
| `honey` | мёд на складе (выведение в этом круге уже вычтено) |
| `time` | сколько секунд идёт матч |
| `count(тип)` | сколько живых пчёл типа `Scout`, `Collector` или `Worker` |
| `hatch(тип)` | вывести пчелу за мёд; сразу `True` (личинка в улье, мёд списан) или `False` (мёда или места нет) |
| `set_home_energy(%)` | порог автовозврата: 0–90, сначала 30; 0 — никогда |
| `set_refuel_energy(%)` | до скольких процентов заправляется вернувшаяся сама пчела, сначала 100 |
| `say(слово, место)` | сказать у летка (слышат пчёлы в 15 м и те, кто дома) |
| `heard` | что улей услышал у летка |
| `wait(секунды)` | подождать |

```python
class MyHive(Hive):
    def loop(self):
        if self.honey > 30:
            self.hatch(Collector)
        self.set_home_energy(25 if self.time < 120 else 40)  # рискуем в начале, бережём к концу
        self.wait(5)                                          # решать раз в 5 секунд
```

Цены и время выведения по умолчанию (`economy.breeding`): разведчик 3 мёда / 30 с, сборщик 4 / 30 с,
домашняя 2 / 20 с; время делится на √(число нянек). На старте у улья 20 мёда и 5 разведчиков,
15 сборщиков, 10 домашних. Пчёл (с личинками) — не больше предела профиля.

**Домашние пчёлы** (`Worker`) работают по одному правилу: нектара на складе больше 0.05 →
перерабатывают (1 нектар → 0.5 мёда, скорость растёт как √n), иначе есть личинки → нянчат,
иначе отдыхают. Каждая ест 0.002 мёда в секунду; без мёда не работает.

## 6. Экономика и победа

Сборщик набирает нектар на цветке → несёт в улей (`go_home`, выгрузка сама) → домашние пчёлы
превращают 1 нектар в 0.5 мёда. Мёд тратится на заправку пчёл в улье (1 мёд = 4000 Дж), еду
домашних и новых пчёл. Побеждает улей, у которого в конце матча больше мёда.

## 7. Враги и погода

- **Шершней и охранников нет** (DECISIONS №82).
- **Пауки** (если включены): сидят на части цветов и кусают сборщиков, которые собирают нектар.
  Разведчик ближе 4 м видит паука: `flower.spider == True`.
- **Погода**: ясно, ветер (сносит пчёл), дождь (полёт тяжелее, обзор меньше).

Пауков и погоду можно выключить в матче (`enemies.spiders.enabled: false`, `weather.enabled: false`)
или переключателями в панели «Матч» редактора.

## 8. Ограничения для скрипта

- Скрипт выполняется в отдельном процессе-раннере; `input()` не работает, `print()` идёт в лог.
- Неверные аргументы (`None` вместо цели, не число, неизвестный цвет или тип пчелы) — исключение
  `TypeError` или `ValueError` с понятным русским текстом.
- Скрипт может импортировать соседние файлы из своей папки и стандартную библиотеку.
- В редакторе можно править только свои файлы в `examples/bees/`; `template.py` и `example_*.py`
  — справочные, их копируют через «Сохранить как».
- Старые скрипты (`step`, `s.`, `yield`), проекты `.swarm` и реплеи до M8 не работают (DECISIONS №88).

## 9. Проект и серия матчей

**Проект** — файл `.swarm` с кодом одного улья (и блоками, если скрипт собран из блоков). Настроек
матча и соперников в нём нет: их выбирают при запуске, чтобы проверять код в разных условиях.

- **Экспорт** — в редакторе «⬇ Экспорт проекта»: браузер скачает `<имя>.swarm`. Если в блоках или
  в Python есть ошибки, редактор предупредит, но экспортировать даст.
- **Открыть в редакторе** — «📂 Открыть проект…» (или перетащите `.swarm` в окно редактора):
  проект станет вашим новым скриптом в `examples/bees/`; если имя занято, редактор предложит другое.
- **Загрузить в меню** — «📂 Загрузить проект .swarm…» (или перетащите файл в окно меню).
  Проект ляжет в папку `projects/` (в редакторе её не видно). Тот же файл второй раз — тот же
  проект; другой файл с тем же именем — новый проект `<имя>-ГГГГММДД-ЧЧММ`, старый не затирается.
- Перед первым запуском чужого проекта меню спросит: «Код из этого проекта выполнится на вашем
  компьютере…». Браузер запоминает именно этот код; изменённый файл спросит снова.

**Серия** — один и тот же матч на разных seed подряд: сразу видно, на каких условиях алгоритм
проигрывает. «Серия…» есть и в меню (у каждого улья — пример или проект), и в панели «Матч»
редактора. Из командной строки:

```powershell
swarmlab series configs/matches/demo.yaml --n 10 --seed 1 --set "hives=[{script: examples/bees/my_bees.py}, {script: examples/bees/example_basic.py}, {script: examples/bees/example_smart.py}]"
```

- Матч i идёт с seed `начальный + i`; без `--seed` начальный выбирается случайно и печатается.
  Тот же начальный seed и те же скрипты на той же машине дают те же реплеи.
- `--jobs N` — сколько матчей сразу (по умолчанию физических ядер − 1); на результат не влияет.
- Всё сохраняется навсегда в `replays/series/<дата>-<проект>/`: реплей каждого матча
  `s<seed>.swr`, `series.json` (настройки, sha256 кода каждого улья — какая версия играла, все
  цифры) и `results.csv` для Excel (в pandas: `pd.read_csv(..., sep=";", decimal=",")`).
- Таблица — по улью проекта (`--team`, по умолчанию первый улей): место, мёд, доставлено нектара,
  живые пчёлы, гибели (энергия / паук) и ошибки кода (исключения, пропущенные тики,
  превышения бюджета). Строки с ошибками кода подсвечены. Внизу — средние, победы и худший
  seed; «Смотреть» открывает реплей матча с перемоткой.
