# Спецификация модуля «Swarm Logic» (пчёлки)

Все числа ниже — **стартовые значения для балансировки**. Они живут в `configs/bees/defaults.yaml`, а не в коде. Где число выведено из цели («сборщик летает ~4 минуты»), реализуй цель и подбери число, а не наоборот.

Единицы: 1 единица длины = 1 м, время в секундах, масса в кг, сила в Н, энергия в Дж. Нектар и мёд — условные единицы (ед.).

Масштаб игровой, не биологический: пчела размером с мяч, чтобы её было видно на карте 300 м и чтобы физика была устойчивой при dt = 5 мс.

---

## 1. Мир

- **Карта:** квадрат `map_size` (профиль «Средний» — 300×300 м), потолок полёта — 30 м над рельефом.
- **Рельеф:** heightfield MuJoCo, сетка 128×128, fBm-шум из `rng("world")`, перепад до 8 м.
- **Препятствия:** деревья (ствол-капсула + крона-сфера, обе твёрдые), камни (боксы). Плотность из профиля. Не ставятся ближе 15 м к ульям.
- **Цветы:** кластеры (поляны). Цветок — **не физическое тело**: это запись в массиве (позиция, нектар, флаг паука). Пчела может висеть над цветком, цветок пчелу не толкает.
- **Ульи:** 1–3, статичные боксы с «летком» (точка входа). При трёх ульях — вершины треугольника со стороной ~150 м вокруг центра. Цветы распределены так, чтобы у каждого улья были сопоставимые поляны (честность).
- **Границы:** мягкие стенки — сила, возвращающая к карте, + автопилот обрезает цели по границам.
- Генерация полностью определяется seed.

## 2. Физика

### 2.1 Тело пчелы

Свободное тело MuJoCo (freejoint), геометрия — сфера. Вращение не важно для игры: угловые скорости демпфируются, ориентация во вьюере берётся по вектору скорости.

| Параметр | Разведчик | Сборщик | Охранник |
|---|---|---|---|
| Радиус, м | 0.20 | 0.25 | 0.35 |
| Масса пустой, кг | 0.05 | 0.08 | 0.15 |
| Макс. груз нектара, ед. (масса) | — | 1.0 (0.04 кг) | — |
| Макс. тяга `T_max`, Н | 1.2 | 1.8 | 3.0 |
| Цель: крейсерская скорость, м/с | ≈ 8 | ≈ 5 пустой | ≈ 6 |
| Радиус обзора, м | 25 | 8 | 12 |
| Цель: время полёта на крейсерской скорости | ≈ 5 мин | ≈ 4 мин | ≈ 3 мин |

Домашняя пчела (`HouseBee`) не летает и **не имеет физического тела** — она существует только внутри улья.

### 2.2 Силы (применяются каждый шаг физики, векторно для всех тел)

- **Тяга** — от автопилота или прямой команды, `|T| ≤ T_max`.
- **Гравитация** — MuJoCo для массы пустой пчелы. Груз меняет и вес, и инерцию: предпочтительно менять `model.body_mass` слота пчелы при изменении груза (проверить тестом, что ускорение при одинаковой тяге падает с грузом); если это ломает что-то в MuJoCo — добавлять силу `m_cargo·g` вниз и учитывать `m_cargo` в автопилоте и в сопротивлении разгону. Решение записать в `DECISIONS.md`.
- **Сопротивление воздуха** — квадратичное по скорости относительно воздуха:
  `F_drag = −c_d · |v − w| · (v − w)`, где `w` — ветер в точке пчелы.
  `c_d` по типу подбирается из крейсерской скорости: горизонтальный запас тяги `√(T_max² − (mg)²) = c_d · v_cruise²`.
- **Ветер** `w(x, y, z, t)`:
  - базовый вектор по состоянию погоды (см. §6), направление медленно поворачивается;
  - профиль по высоте (степенной закон приземного слоя): `|w|(z) = w_ref · (z_agl / 10)^0.14`, при `z_agl < 1` — как при 1 м;
  - порывы: сумма 3–4 синусоид по времени и координатам с фазами из `rng("weather")` (дёшево, гладко, детерминированно).
- **Дождь:** дополнительная сила вниз `F_rain = k_rain · r²` и множитель сопротивления ×1.3.
- **Мягкие стенки и потолок** — пружина за пределами карты/потолка.

### 2.3 Энергия

Мощность — модель идеального винта (теория импульсного диска): индуктивная мощность растёт как `T^1.5`.

`P = P_idle + k_p · |T|^1.5`, `E -= P · dt`.

`E_max` и `k_p` подбираются так, чтобы выполнялись цели «время полёта» из §2.1. Висение тоже тратит энергию (как у реальных дронов).

При `E = 0` тяга = 0: пчела падает и после касания земли погибает. В улье энергия восполняется за мёд (§4.4).

### 2.4 Столкновения (битовые маски MuJoCo `contype/conaffinity`)

| Тело | Сталкивается с |
|---|---|
| Рельеф, деревья, камни, ульи | всеми летающими |
| Пчела | пчёлами (любых ульев), шершнями, статикой |
| Шершень | пчёлами, статикой |
| Цветок | ни с чем (не тело) |

Пчёлы внутри улья и погибшие — «припаркованы» (пул тел, см. ARCHITECTURE §3.5) и не сталкиваются.

## 3. Управление

### 3.1 Модель

Гибридная: у каждой летающей и домашней пчелы свой `step()`, у улья — необязательный `hive_step()`. Пчела знает только свои сенсоры. Объекты пчёл живут в раннере между тиками — можно хранить память в `self`.

`step()` вызывается 10 раз в секунду (тик решений). Внутри `step()` пчела вызывает методы-команды; последняя вызванная команда движения побеждает. Если пчела ничего не вызвала — продолжает предыдущую команду.

### 3.2 Файл игрока

```python
from swarmlab.bees.api import Scout, Forager, Guard, HouseBee, Hive, Sensors


class MyScout(Scout):
    def step(self, s: Sensors): ...


class MyForager(Forager):
    def step(self, s: Sensors): ...


class MyGuard(Guard):
    def step(self, s: Sensors): ...


class MyHouse(HouseBee):
    def step(self, s): ...


def hive_step(hive: Hive):  # необязательно
    ...
```

Раннер находит по одному подклассу каждого типа (если подкласса нет — используется базовый со встроенным простым поведением).

### 3.3 Команды

**Движение (уровень «детский», по умолчанию):**

| Команда | Кто | Что делает |
|---|---|---|
| `fly_to(x, y, z=None, speed=None)` | все летающие | автопилот к точке; `z=None` — держать 5 м над рельефом |
| `fly_dir(dx, dy, dz)` | все | лететь в направлении |
| `hover()` | все | висеть на месте |
| `go_home()` | все | к летку и войти в улей |
| `leave_hive()` | все в улье | вылететь из улья |
| `collect(flower_id)` | сборщик | подлететь к цветку, зависнуть над ним, набирать нектар, пока не полон / цветок не пуст |
| `unload()` | сборщик в улье | выгрузить нектар в хранилище |
| `intercept(target_id)` | охранник | преследование с упреждением |

**Движение (уровень «продвинутый», только при `advanced_control: true` в матче):**
- `thrust(fx, fy, fz)` — прямой вектор тяги, автопилот отключён.

**Дополнительно (можно вместе с командой движения):**
- `signal(*values)` — сообщение до 8 чисел соседям своего улья в радиусе связи (§5.1).
- `mark(channel, amount=1.0)` — оставить феромон (§5.2).

**Домашняя пчела:** `process()`, `nurse()`, `rest()`.

**Улей (`hive_step`):** `hive.breed(kind, n=1)`, `hive.cancel_breeding(kind)`, `hive.signal(*values)` — сообщение пчёлам в радиусе связи от улья. Хранить память можно в `hive.memory` (dict).

### 3.4 Автопилот

Векторный PD-регулятор для всех пчёл сразу на частоте физики:
`a_des = Kp·(p* − p) + Kd·(v* − v)` → `T = m·(a_des + g) + компенсация сопротивления` → ограничение `|T| ≤ T_max` с приоритетом вертикальной составляющей (сначала удержать высоту, остаток — на горизонталь).

- Реализация (DECISIONS №24): `a_des = Kd·(v_ref − v)`, `v_ref = clip(Kp/Kd·(p* − p), speed)` — в линейной зоне это тот же PD, вдали от цели скорость ограничена. Тяга вниз не создаётся.
- Держит минимальный просвет 1.5 м над рельефом.
- `avoid_obstacles` (по умолчанию включено): отталкивание от видимых препятствий — потенциальное поле. Можно выключить в `fly_to(..., avoid=False)` — для старших, кто пишет свою навигацию.

## 4. Экономика улья

### 4.1 Хранилище
Нектар (ед.), мёд (ед.). Старт: мёд 20, нектар 0. **Мёд не появляется сам по себе** — только переработкой принесённого нектара.

### 4.2 Сбор
Сборщик над цветком (горизонтально ≤ 1 м, высота над цветком ≤ 1.5 м, скорость < 0.7 м/с) набирает 0.25 ед./с, пока не полон. Цветок: максимум 3 ед., восстановление 0.02 ед./с.

### 4.3 Переработка
Домашние пчёлы с командой `process()` перерабатывают нектар:
`скорость = k_proc · √n_process` ед. нектара/с (убывающая отдача), `k_proc = 0.1`. Выход: 1 ед. нектара → 0.5 ед. мёда. Переработка не идёт без нектара.

### 4.4 Питание
- Летающая пчела в улье автоматически заправляется: 1 ед. мёда = 2000 Дж, скорость заправки 200 Дж/с.
- Каждая домашняя пчела потребляет 0.002 ед. мёда/с.
- Нет мёда → заправки нет, домашние пчёлы не работают.

### 4.5 Выведение
`hive.breed(kind)` ставит личинку в очередь и сразу списывает мёд:

| Тип | Цена, мёд | Базовое время, с |
|---|---|---|
| Разведчик | 3 | 30 |
| Сборщик | 4 | 30 |
| Охранник | 6 | 45 |
| Домашняя | 2 | 20 |

Время выведения = базовое / `√max(1, n_nurse)` — нужны домашние пчёлы на `nurse()`. Лимит пчёл улья — `max_bees` из профиля.

### 4.6 Стартовый состав
5 разведчиков, 15 сборщиков, 5 охранников, 10 домашних.

## 5. Сенсоры и связь

### 5.1 `Sensors` летающей пчелы

| Поле | Содержимое |
|---|---|
| `tick`, `time` | номер тика, время матча |
| `me` | `id, kind, pos, vel, energy, energy_max, cargo, cargo_max, in_hive, alive` |
| `home` | `pos` (леток), `dir`, `dist` — пчела всегда знает направление домой |
| `ground_z` | высота рельефа под пчелой (альтиметр) |
| `airspeed` | вектор ветра в точке пчелы (датчик воздушной скорости) |
| `weather` | `"clear" / "windy" / "rain"` — текущее, без прогноза |
| `flowers` | видимые цветы: `id, rel_pos, nectar` (+ `spider` — только у разведчика ближе 4 м) |
| `bees` | видимые пчёлы: `id, rel_pos, vel, kind, team` |
| `enemies` | видимые враги: `id, kind, rel_pos, vel` |
| `obstacles` | видимые препятствия: `rel_pos, radius` |
| `messages` | сообщения прошлого тика от своих в радиусе связи: `from_id, rel_pos, values` |
| `pheromones` | 3×3 клетки вокруг: значения 4 каналов + градиент |

«Видимые» = в радиусе обзора типа (дождь: ×0.7). Всей карты пчела не видит.

**Шум сенсоров** (`sensor_noise: true` в матче): гауссов шум позиций σ=0.3 м, скоростей σ=0.1 м/с, из `rng("sensor_noise")`. Выключен в песочнице, включён в соревновательных пресетах.

### 5.2 Связь
- `signal(...)`: до 8 чисел, радиус связи 15 м, доставка на следующем тике всем своим в радиусе (и улью, если леток в радиусе). Только свой улей.
- **Феромоны:** у каждого улья своя 2D-сетка, клетка 2 м, 4 канала, `mark` добавляет значение в клетку под пчелой, испарение с полураспадом 60 с.

### 5.3 Сенсоры домашней пчелы и улья
- `HouseSensors`: `tick, me, hive_nectar, hive_honey, breeding_queue, counts`.
- `Hive`: склад, численность по типам и состояниям (в улье/в полёте), очередь выведения, сообщения от пчёл в радиусе связи летка, `memory`.

## 6. Погода (`weather.enabled`)

Марковская цепь состояний из `rng("weather")`, средняя длительность состояния 90 с:

| Состояние | Базовый ветер `w_ref`, м/с | Дождь |
|---|---|---|
| clear | 0–1 | нет |
| windy | 3–6 | нет |
| rain | 2–4 | да |

## 7. Враги (PvE)

Враги управляются встроенными ботами через **тот же API** (`swarmlab/bees/bots/`), как отдельная «команда» без раннера-процесса (исполняются в процессе симуляции — это доверенный код).

### 7.1 Шершни (`enemies.hornets.enabled`)
- Тело: радиус 0.4 м, масса 0.3 кг, крейсер ≈ 7 м/с, HP 100.
- Волны с края карты каждые 60 с, размер волны `1 + floor(t / 120)`, одновременно не больше `hornets_max` из профиля.
- Поведение: цель — ближайшая видимая пчела, у которой ≤ 1 союзника в 3 м; если таких нет — летит к случайному улью.
- Атака: контакт с пчелой непрерывно 1.5 с → пчела погибает.
- Грабёж: у летка (≤ 3 м) и нет охранников в 5 м → крадёт 0.2 ед. мёда/с.
- **Защита «тепловой шар»** (как у настоящих пчёл против шершней): если вокруг шершня ≥ 2 охранника на расстоянии ≤ 1 м от поверхности — урон 10 HP/с за каждого. HP < 30 → шершень улетает к краю; HP = 0 → погибает.

### 7.2 Пауки (`enemies.spiders.enabled`)
- 10% цветов с пауком (выбор по seed). Паук неподвижен.
- Сборщик, собирающий на таком цветке: каждую секунду вероятность гибели 0.15.
- Видит паука только разведчик ближе 4 м (поле `spider` у цветка). Передать знание остальным — задача кода игрока (сигналы, феромоны).

## 8. Матч и счёт

- `duration_s` (демо — 300 с), тик решений 10 Гц.
- **Победа:** больше мёда на складе в конце. Тай-брейки: весь доставленный нектар → живые пчёлы.
- **Выбывание:** нет живых пчёл, или нет летающих и мёда меньше цены самой дешёвой пчелы.
- События в реплей: рождение, гибель (причина), доставка, атака, тепловой шар, смена погоды.

## 11. Примеры для игроков (`examples/bees/`)

- `template.py` — пустой шаблон с подробными русскими комментариями: что такое `step`, какие есть сенсоры и команды.
- `example_basic.py` — сборщики летят к ближайшему видимому цветку или ищут случайно, возвращаются полными; улей выводит сборщиков, пока есть мёд.
- `example_smart.py` — разведчики сообщают координаты полян и пауков; сборщики выбирают цветок по расстоянию и нектару; охранники патрулируют у улья и собираются в тепловой шар; улей держит пропорции типов и число домашних под поток нектара.
