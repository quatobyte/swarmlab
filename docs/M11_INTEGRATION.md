## Ограничения проверки

- Полное ручное прохождение миссий 2–8 и всех их страниц не выполнялось; все восемь
  сценариев проверяются настоящими headless-матчами и тем же JS-судьёй.
- В серверном логе при разрыве WebSocket на Windows наблюдался `ConnectionResetError: [WinError 10054]` из `_ProactorBasePipeTransport._call_connection_lost`. Зависания UI и потери программы не было; обработчик транспорта Python в рамках интеграции не менялся.
- Linux/nsjail не запускается на Windows; соответствующие 8 тестов имеют явный skip.
- Гостевой вход в публичный портал уже был заглушкой `master` («Режим появится позже»).
  Это поведение проверено и сохранено; новый гостевой режим не создавался.
- Прогресс хранится в браузере, без серверной синхронизации и привязки к аккаунту (№100).
  Код `tutorial.py` на портале хранится отдельно у каждого пользователя.
- Публикация на производственный сервер и приёмка Лео не выполнялись; статус M11 — 🟨.
